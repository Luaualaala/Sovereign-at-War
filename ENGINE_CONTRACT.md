# Sovereigns at War — integration contract

All source uses classic browser JavaScript, no dependencies. Each file attaches to `globalThis.GS`. Load order: data.js, core.js, research.js, warfare.js, systems.js, ui.js. Node tests use the same files via require (namespace exports globally). Simulation has no DOM, wall-clock or Math.random. `GS.rand(s)` seeded RNG [0,1); `GS.clamp(x,min=0,max=100)`, `GS.log(s,type,text,countryId=null,regionId=null)` (chronicle + alerts), `GS.country(s,id)`, `GS.region(s,id)`, `GS.owned(s,cid)`, `GS.atWar(s,a,b)`, `GS.rel(s,a,b)`, `GS.mod(c,key)` additive adopted technology/trait/policy modifier. All state must JSON round-trip.

State: `{version:1,seed,rng,day:0,player:0,options:{ai:1,economy:1,uncertainty:1},countries:[],regions:[],units:[],wars:[],relations:[],chronicle:[],alerts:[],events:[],battles:[],shipments:[],nextId:1000,tension:25,result:null}`. day is whole days, start 1936-01-01. Typical campaign horizon 1460 days. Every country's id numeric, including dynamic civil war states.

Region: `{id,name,x,y,owner,core,terrain:'plains',neighbors:[],population:300000,culture,wealth:50,loyalty:65,unrest:10,resistance:0,compliance:40,autonomy:0,infrastructure:70,rail:1,hub:false,port:false,airfield:0,city:false,river:false,fort:0,industry:2,farms:2,oil:1,materials:2,energy:2,damage:0,housing:100,weather:'clear',supply:0,supplyPath:[],supplyBottleneck:'',supplyCapacity:0,displaced:0,occupation:'civilian'}`. Regions only land; all coastline regions have port potential. Sea abstracted to named coast sectors based x coordinate. Neighbors contain region IDs.

Unit: `{id,country,region,name,type:'infantry',strength:100,maxStrength:100,manpower:6000,equipment:100,organization:80,morale:80,cohesion:75,readiness:80,fatigue:0,stress:0,supply:80,training:55,experience:10,commander:0,order:null,stance:'hold',planning:0,entrenchment:0,history:[],honors:0,losses:0,reliability:85,foreignEquipment:0,mission:'reserve',missionTarget:null}`. Remaining supply/maintenance etc fields can be appended with safe defaults. `GS.issueOrder(s,cid,uid,target,{plan=false,amphibious=false}={})` returns `{ok,message}`; `GS.recruit(s,cid,type)` costs stock+manpower and queues training; `GS.militaryTick(s)` calculates supply, training, orders, combat, air/naval missions, morale and casualties. Export `GS.computeSupply(s,cid)`, `GS.combatPower(s,u,defending=false)`, `GS.militaryAI(s,cid)` consumes only c.intel.reports for foreign unit positions/strength (terrain/ownership public). `GS.visibleRegions(s,cid)` -> Set of friendly/allied accessible/neighbor regions. `GS.intelligenceTick(s)` implemented parent updates reports before militaryAI; report per region `{day,confidence,min,max,units:[{type,min,max}],source,deceptionSuspected}`. Never render actual enemy unit state.

Relations array each pair `{a,b,opinion:0,trust:50,alliance:false,access:false,guarantee:null,pactUntil:0,sanctions:[],trade:null,aid:0}`. DATA exports: countries 8 objects template `{id,name,short,color,flag,government,description,focus,doctrine,starting:{...numeric overrides}}`; governments map reusable `{name,executive,accountability,elections,delay,repression,succession}`; laws array `{id,name,category,description,options:[{id,name,description,effects:{...}}]}` (>=30 named policy options; parent applies); unitTypes map >=15 families `{name,domain:'land'|'air'|'naval',attack,defense,speed,fuel,ammo,supply,cost,manpower,days,reliability,tech?}`; terrains map `{color,defense,move,supply,visibility}`; commanderTraits/politicalTraits arrays >=30 `{id,name,description,effects:{}}`; events >=40 `{id,name,description,condition:{metric,op,value},options:[{label,effects:{}}]}`; techs array 250+ `{id,name,branch,era,cost,prereqs:[],description,effects:{},unlock?}`; branches `{id,name,color}`; doctrines map. Do not make hundreds of merely renamed flat bonuses: branched capability unlocks and meaningful operating tradeoffs, cross prerequisites.

Research module: `GS.initResearch(c)` creates institutions and research state; `GS.queueResearch(s,cid,techId,institutionId?)` returns result, prerequisites traced/queued; `GS.researchTick(s)` finite institutional budgets, ahead-era penalty, theory->prototype->engineering->adoption stages, production/treasury costs and field rollout. `GS.researchStatus(c,techId)` readable status; `GS.licenseTechnology(s,from,to,techId)` charges treasury transfers engineering progress; `GS.availableTech(c)`; `GS.researchAI(s,cid)`. Set adopted modifier aggregate c.techMods; GS.mod reads it. Research must not finish all in 1460 days. Add public `GS.researchEffects` explanations if useful.

Parent supplies createGame, political/economic/diplomatic/intel/event ticks, UI and save server. Do not mutate others' project files: helpers build in their own registered+claimed scratch scopes, provide final paths, parent integrates. Communicate contract changes first.

## UI and central actions

`GS.createGame({player=0,seed=1936,scenario='powderkeg',ai=1,economy=1,uncertainty=1})`, `GS.tick(s,days=1)` returns state, `GS.act(s,cid,type,payload={})` returns `{ok,message}`. `GS.snapshot(s)` returns JSON string save envelope checksum; `GS.restore(text)` validates and returns state or throws; `GS.publicCountry(s,cid,viewer)` returns estimated public summary. `GS.coupRisk(s,cid)` returns 0..100. `GS.policyEffects(c)` returns aggregate numeric effects. `GS.supplyForecast(s,cid)` if provided warfare.

GS.act actions payload:
- policy `{category,option}` queued with constitutional delay/cost; mobilize `{level:0..3}`; allocation `{military:0..1}`; production `{key,value:0..1}` normalized; labor `{key,value}` normalized; spending `{key,value:.5..2}`.
- build `{region,kind:'rail'|'hub'|'industry'|'farm'|'power'|'fort'|'repair'|'airfield'|'port'|'housing'}` queued cost/time.
- recruit `{unitType}`; order `{unit,target,plan,amphibious}`; stance `{unit,stance:'hold'|'rest'|'train'|'garrison'|'advance'}`; mission `{unit,mission,target}`; commander `{unit,commander}`; doctrine `{doctrine}`.
- appoint `{leader,role}`; promote `{commander}`; purge `{commander}`; reform `{kind:'election'|'constitution'|'anticorruption'|'negotiate'|'monitor'|'arrest'|'patronage'|'succession'}`; propaganda `{theme:'unity'|'victory'|'sacrifice'|'truth'}`.
- diplomacy `{target,proposal:'alliance'|'pact'|'guarantee'|'access'|'sanction'|'trade'|'aid'|'loan'|'influence'|'proxy'|'ultimatum'|'war'|'peace'|'exchange'|'recognize'|'conference'|'license'|'investment',resource:'food',amount:10,aim:'territory'|'regime'|'reparations'|'defense',terms:'white'|'territory'|'reparations'|'regime'|'resources'|'disarmament',tech}`. Reply describes rejection reasons. Trade recurring explicit resource imports paid to partner; aid/proxy delayed shipment.
- intel `{target,operation:'network'|'recon'|'sabotage'|'deception'|'counter'|'cipher'|'coup'|'steal'|'psyops'|'inspect'|'jamming'|'doubleagent',region}`.
- occupation `{region,policy:'civilian'|'collaboration'|'military'|'harsh'|'extract'}`; region `{region,operation:'autonomy'|'negotiate'|'suppress'|'evacuate'|'evacuateIndustry'|'scorch'|'relief'}`.
- research `{tech,institution}`; researchFunding `{funding:.5..2}`; finance `{operation:'bonds'|'print'|'repay'|'reserve'|'release'}`; event `{event,option}`; automate `{system:'production'|'military'|'intelligence',enabled}`; retire `{}`; continue `{}` (after victory/horizon, not annexation).

UI must never read raw foreign troop arrays or foreign country stats to display intelligence; map foreign information uses player's intel.reports and GS.publicCountry. Own detailed troops allowed. Regions and ownership public; hostile industry/resources must be estimated if low intel. Report source confidence age prominently. State events `{id,country,template,name,description,options,day,expires}`; log `{id,day,type,text,country,region}`. Pending policy state c.pendingPolicies array. Economic explanations c.metrics `{daily:{food,fuel,materials,equipment,ammo,parts,goods,transport,treasury},output,labor,energy,transport,civilianNeeds,shortage,reasons:[string],stabilityReasons:[string]}`; c.history array samples `{day,stability,treasury,food,output,inflation,debt,exhaustion}`.

Final integrated additions: `operation {name,unitIds:number[],reserveIds:number[],target,startDay}` schedules a coordinated objective; `strategic {weapon:'demonstrate'|'ballistic'|'nuclear',target}` applies capability gates, preparation intervals, costs and escalation; `recruit` accepts `training:'rapid'|'balanced'|'extended'`; `researchCancel {tech}` preserves useful work; `researchInstitution {tech,institution}` reassigns institutional work with retooling costs. All are exposed by the player interface. `unit.manpower` is current personnel, not full strength multiplied by a percentage. Destroyed formations remain in history and must be excluded from current totals. `country.prisoners[origin]` records custody by origin. Imported/captured equipment enters `foreignEquipmentStock`, which is allocated during equipment replenishment. Naval interception accumulates shipment loss and importing/exporting ports both affect sea trade. `jammedUntil` creates real command delay. Percentage public estimates are bounded at 100; money, population and resources remain unbounded estimates. The complete daily ledger is finalized after every system tick. The simulation module cache is cleared even after an exception.
